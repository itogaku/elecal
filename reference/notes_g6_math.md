## 0. 資料の概要

  ＋ 付録「計算ミニドリル」28回 ＋ 付録「かくにんテスト」28回 ＋ 答え（別冊）

## 1. 見開き1単元の基本フォーマット（＝サイトのテンプレート候補）
| 位置 | 中身 |
|---|---|
| 左ページ上 | **ポイント**：要点を2つ程度に枠囲みでまとめる（用語・公式・図） |

- 章末に **発展**（例：数の列を文字で表す、暗証番号の組み合わせ、角すいの体積、最大値・最小値・範囲、階級の幅を変える）。

## 2. 単元の流れ（学習指導要領ベースの一般的な順序）
1. 5年の復習（2回）
2. 対称な図形：線対称 / 点対称 / 多角形と対称
3. 文字と式：文字を使った式 / 式のよみ方
4. 分数×整数・分数÷整数
5. 分数×分数：かけ算(1)〜(3)（帯分数・小数混じり・積の大きさ）/ かけ算の活用（面積・時間を分数で）/ 逆数・計算のきまり
6. 分数÷分数：わり算(1)〜(3)（商の大きさ）/ 割合を表す分数
7. 場合の数：並べ方 / 組み合わせ / 条件整理
8. 円の面積(1)(2)（公式・組み合わせた図形）
9. 立体の体積（角柱・円柱・複合立体）
10. データの整理と活用：代表値（平均・中央値・最頻値）/ ドットプロット / 度数分布表・ヒストグラム / 人口ピラミッド等の読み取り
11. 比とその利用：比・比の値・等しい比 / 比を簡単にする（小数・分数の比）/ 比を使った問題（全体を比で分ける）
12. 拡大図と縮図：性質 / かき方（方眼・辺と角・1点を中心に）/ 縮尺の利用
13. 比例と反比例：比例の性質・式・グラフ / 比例の利用 / 反比例の性質・式・グラフ
14. およその形と大きさ（概形の面積・体積）/ 単位の関係（長さ・面積・体積・重さ）
15. 考える力の単元：表を使って規則を見つける / つるかめ算的な問題 / 見積もり（切り上げ・切り捨て）/ 全体を1とみる（仕事算・旅人算的）/ 論理パズル（順位あて）
16. プログラミング的思考（1〜100の表で条件に合う数に印）
17. 6年のまとめ（2回）、資料の活用問題（グラフ作成・読み取り）

## 3. 問題の型（＝サイトで自動生成できそうなもの）
- **計算ドリル型**：分数×÷整数、分数×÷分数、帯分数、小数混じり、3つの数の計算、計算のきまり、逆数、比の値、比を簡単に、x を求める（a:b = c:x）
- **穴埋め型**：単位換算（m²⇔cm²、L⇔cm³、時間⇔分の分数表示 など）
- **表を埋める型**：比例・反比例の x,y 表、規則性の表、場合の数の表
- **グラフ型**：方眼に比例・反比例のグラフ、ヒストグラム、ドットプロット
- **作図型**：方眼上で線対称・点対称の図形を完成、拡大図・縮図（方眼）
- **図形計算型**：円・おうぎ形・組み合わせ図形の面積、角柱・円柱の体積（図はSVGで自作）
- **文章題型**：割合を表す分数、比の配分、比例の利用、速さ、見積もり
- **データ型**：数値列から平均・中央値・最頻値・範囲、度数分布表

## 4. 付録の形式
- **計算ミニドリル**：1回＝5セクション×4問、各セクションに得点欄。5年までの基礎（たし算〜比、小数、分数、単位）を28回。
- **かくにんテスト**：1回1ページ、問題は左、**解答欄は右側の縦枠**（配点つき）。本編の単元に対応。
- 答えは別冊（縮小版の紙面に赤字）。→ サイトでは「問題ページ＋解答ページ」を同時生成するのが良い。

## 5. 使わないもの（著作権・独自性の観点）
- 問題文・具体的な数値・例題の言い回しのコピー
- 図版・イラスト・写真・キャラクター・読み物（コラム、パズル）の内容
- 紙面デザイン（色・アイコン・見出しの装飾）そのもの
- 資料独自の単元タイトル（「〜の準備」「〜を探せ！」のような名前）→ 一般的な名称を使う

## 0. 資料の概要

## 1. 章の流れ（この順にサイトの6年を並べる）
1. 分数のかけ算（分数×整数 → 分数×分数 → 積の大きさ）
2. 分数のわり算（分数÷整数 → 分数÷分数 → 商の大きさ）
3. 分数のいろいろな計算（逆数、小数・整数まじり、帯分数、四則混合、計算のくふう）
4. 分数の利用（時間を分数で表す、速さ・面積・体積を分数で）
5. 割合（分数で表す割合：くらべる量・もとにする量、割合×割合）
6. 比（比・等しい比・簡単な比 → 比の利用 → 3つの数の比・かげの長さ）
7. 対称な図形（線対称 → 点対称 → 多角形と対称）
8. 拡大図と縮図（性質・かき方 → 長さの求め方 → 縮図の利用・縮尺）
9. いろいろな面積（円の面積 → おうぎ形 → およその面積）
10. 角柱や円柱の体積（体積 → 表面積）
11. 文字と式（xを使った式 → xを求める問題）
12. 比例（ともなって変わる量 → 比例 → 比例のグラフ）
13. 反比例（反比例 → 反比例のグラフ）
14. 場合の数（並べ方・コインの表裏 → 組み合わせ・勝ち抜き戦 → セットメニュー・道順・金額）
15. 資料の調べ方（代表値・ドットプロット → 度数分布表・柱状グラフ → 区切り方・のべ人数）
16. 中学への準備（総復習）
- 思考力：分数の積と差、四角形の面積二等分、縮図の利用、円の面積（ピザの比較）、規則性、場合の数、資料の調べ方、プログラミング（グラフをかく手順）

## 2. 説明の見せ方の型（サイトの「なぜ？」図の参考）
- 分数×整数・分数÷整数：1dLでぬれる面積を、1m²の正方形を等分した面積図で示す
- 分数×分数：1m²の正方形をたて・よこに分けた面積図（かけた分だけの小さな長方形を数える）
- 分数÷分数：数直線（4目もりで□なら1目もりは□÷4、5目もりで…）→ 逆数をかける理由
- 積・商の大きさ：テープ図で、1より小さい数をかけると小さくなることを見せる
- 割合：テープ図・数直線で「もとにする量＝1」
- 比：カップの数で 2:3 と 4:6 が同じ味になることを見せる
- 円の面積：円を細かいおうぎ形に切って並べかえ、長方形に近づける
- 体積：1cm³の立方体を底面に並べ、高さの分だけ積み上げる
- 比例・反比例：表の上に「×2、×3」の矢印をかく
- 場合の数：表と樹形図を並べて示す
