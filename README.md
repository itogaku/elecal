# さんすうプリント工房

小学1〜6年の算数と脳トレパズルのプリントを、ブラウザだけで自動作成してA4で印刷するサイトです。

- 単元を選ぶと、数値がランダムに変わる問題プリントが何枚でも作れます（問題番号を同じにすると同じ問題を再現できます）
- 解説ページ：ポイント → 「なぜ？」の図解 → 例題 → ここに注意
- 答えのページ：赤字の答えと、解き方（途中式・考え方）
- 問題の量（半分〜5枚分）・セット数（1〜10セット）・まとめテスト（100点満点）を選べます
- 6年・5年は参考教材の章立てに合わせた構成、1〜4年は学習指導要領にそった単元構成

## 使い方

`index.html` をブラウザで開き、学年と単元を選んで「印刷する」を押します（PDFとして保存もできます）。
GitHub Pages を有効にすると、そのままWebサイトとして公開できます。

## ファイル構成

- `index.html` … 完成版（このファイルだけで動きます）
- `src/app.html` … 画面とデザイン（HTML/CSS）
- `src/script.js` … 6年の基本単元と、画面・印刷・ページ分けのプログラム
- `src/grades.js` … 1〜5年の単元と脳トレ・パズル
- `src/more.js` 〜 `src/more8.js` … 図・グラフ・文章題・なぞり問題などの追加の問題タイプ、章の並べかえ（6年は資料B・C、5年は資料D）、5年の追加の型（資料E）、「なぜ？」の図（`WHY`）
- `src/more6.js` … 1枚あたりの問題数（`PER_PAGE`）と2列にする単元
- `build.sh` … `src/` から `index.html` と `dist/preview.html`（印刷ボタンなしのプレビュー版）を作り直す
- `reference/notes_g6_math.md` … 参考にした教材（小6を3冊、小5を2冊）の構成・問題の型・説明の型のメモ（問題文・数値・図は写していません）

## 単元の追加

`addUnits(学年, '章の名前', [ {id, title, kind, n, cols, lead, explain, gen()} ])` で追加します。
`gen()` は `{ q: 問題, a: 答え, steps: [解き方] }` を返します。`q` に `{_}` を入れると空らんになり、`blanks` 配列で複数の空らんの答えを指定できます。
「なぜ？」の図は `WHY['単元id'] = () => [{ svg, cap, lines }]` で追加します。

編集したら `./build.sh` を実行して `index.html` を作り直してください。
